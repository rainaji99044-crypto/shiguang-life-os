# 拾光 Life OS V2.4

一个移动优先、可离线使用的个人 Life OS 工作台。项目由原生 HTML、CSS 和 JavaScript 构成，不依赖 ChatGPT、OpenAI 组件、账号登录或自建服务器。

## 数据说明

- 所有任务、习惯、日记和私人资料默认保存在当前浏览器的 `localStorage`。
- 数据不会提交到 GitHub，也不会在电脑与手机之间自动同步。
- 在「我的 → 更多」中可以导出完整 JSON 备份，也可以导入备份恢复数据；导入前会提示确认。
- V2.2 会自动迁移旧版习惯、课程与课堂记录；重复打开或刷新不会重复导入课表。旧记账金额记录继续保留在备份数据中，但不再显示或转换成习惯打卡。

## V2.2 学业模块

- 已按《2026-2027（1）MPAcc课表-26级集中班》录入 5 门课程、43 个课程/考试时段与 3 个活动事项。
- 课程、教师、日期、上午/下午/晚上、时间和教室均按课表保存；未明确的信息统一显示“待通知”。
- 支持周课表、日期列表、下一次上课、课程详情、站内提醒、课程作业、成绩学分、课堂收获和本地附件。
- 四学期时间线与培养要求标注为“学校课堂展示资料”，未把待通知事项虚构为确定日期。
- 课程提醒是网页内提醒；静态网页未实现浏览器关闭后的后台推送。

## V2.4 阅读与视频工作流

- 「学习 → 阅读」在原书库内整合培养方案第3页的17本推荐书，保留原序号、作者、版本、出版社和年份，并提供P1/P2/P3个人推荐排序。
- 推荐书默认是“想读”，不会自动生成阅读任务、购买状态或截止日期；原有个人书籍与阅读进度继续保留。
- 「研究生 → 学业安排」仅提供推荐阅读入口，不创建第二套重复书库。
- 「探索 → 工作项目」增加视频发布月历和日期列表，与脚本库共用同一份数据，支持项目、平台和制作状态筛选。
- 已导入FARMA抓木机第一期、第二期视频脚本；原始口播独立保留，可另存修改稿，拍摄清单支持逐项勾选。
- 视频平台与链接仅作本地记录，网页不会自动连接或发布到抖音、小红书等平台。

## 直接使用

部署后直接访问网址即可，不需要安装开发工具。支持 Windows 浏览器、iPhone Safari 和添加到主屏幕。

开发预览可在项目目录运行 `npm start` 后访问 `http://localhost:4173`，这只用于开发检查，不是正常使用的必要条件。

## GitHub Pages 部署

项目包含 `.github/workflows/pages.yml`，把完整项目上传到 GitHub 仓库后：

1. 打开仓库的 **Settings → Pages**。
2. 在 **Build and deployment → Source** 中选择 **GitHub Actions**。
3. 推送到 `main` 分支后，GitHub 会自动发布 `dist` 目录。

网站使用相对资源路径和 `#` 路由，兼容 GitHub Pages 子路径，刷新不会产生路由空白页。
